UNIVERSITY PASSWORD CHANGES

A university password is used by several services, including Wi-Fi, email, VPN, and university applications.

After changing a password:
- Some devices and applications may continue using cached old credentials.
- Services already signed in may continue working temporarily.
- A device may need to forget and reconnect to a network before it asks for the new password.
- Saved passwords in email clients or VPN software may need to be updated.

If one device fails after a password change while another still works, check whether the failing device has stored old credentials.

Repeated authentication attempts using an old password may temporarily lock an account.
